
# JANU AI

JANU AI is my personal AI assistant.

## Features
- Hindi and English conversation
- Female-style voice assistant
- Voice input and voice replies
- Wake word activation: Janu
- Clap detection
- AI chat and conversation memory
- Reminders and task management
- Background task support where Android allows it

## Project Goal
Create a complete Android application and installable APK for JANU AI.
